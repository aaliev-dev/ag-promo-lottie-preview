# promo_power_up — превью

Локальное превью «было / стало» для замены щита в Lottie-анимации `promo_power_up`.

- `index.html` — превью с воспроизведением, тёмной/светлой темой и скачиванием JSON.
- `assets/lottie_promo_power_up.json` — обновлённая анимация 258×182.
- `assets/lottie_promo_power_up_sw361dp.json` — обновлённая анимация 360×298.
- `assets/lottie_promo_power_up_light.json` — светлая тема, 258×182.
- `assets/lottie_promo_power_up_light_sw361dp.json` — светлая тема, 360×298.

Собрано детерминированно из `Shield.svg` и `Pic.svg` скриптом `tools/build.py`.
